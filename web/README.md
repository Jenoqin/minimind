# MiniMind 交互课程

## 第一课：预训练全流程地图

应用目录：[pretrain-lesson-1](pretrain-lesson-1/README.md)。克隆项目后，可在 macOS Finder 中双击 `启动课程.command`，学习结束后双击 `关闭课程.command`。

六个学习环节：训练地图、token 预测、参数更新演示、真实日志曲线、九个概念的第一性原理、课后自测。学习进度和笔记保存在浏览器本地。

从项目根目录启动：

```bash
./web/pretrain-lesson-1/启动课程.command
```

关闭：

```bash
./web/pretrain-lesson-1/关闭课程.command
```

课程讲义：[第 1 课](../docs/learning/01_预训练全流程地图.md)。
